About TIMECODE::STEGSVG

🌈

7D Multi-Channel Encoding

Distributes data across 7 dimensions: X, Y (position), Z (layer), T (time), C (color), A (alpha), F (frequency)

🔐

Built-in Encryption

Optional encryption with visual keys, gzip compression, and error correction codes

🎨

Beautiful Output

Generate visually appealing SVGs in multiple artistic styles

✅

Data Integrity

Checksum verification ensures data hasn't been corrupted

Technical Details

  • Compression: Gzip compression reduces data size by up to 70%
  • Encryption: XOR cipher with SHA-256 key derivation
  • Error Correction: MD5 checksum with length verification
  • Storage: Data embedded in custom SVG attributes
  • Capacity: 1KB - 10MB+ depending on size and style
  • Security: Below human perception threshold, requires knowledge of system to extract
